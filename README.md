# AI文创 - 明信片作品展

> 一个面向课堂场景的 AI 明信片画廊与打印工具，支持批量加载、浏览和打印 A6 明信片。

**在线体验：** [https://frog1205.github.io/postcard-gallery/](https://frog1205.github.io/postcard-gallery/)

---

## 功能特性

- **文件夹加载** — 点击按钮选择本地图片文件夹，自动解析文件名并排序展示
- **双视图切换** — 卡片网格视图 / 紧凑列表视图，一键切换
- **灯箱浏览** — 全屏大图查看，键盘左右箭头切换，Esc 退出
- **明信片打印** — 自动生成 A6 尺寸（148×105mm）正反面版式，正面满版图片 + 装饰元素，背面含寄语区和地址区
- **离线可用** — 纯前端单文件应用，保存 `index.html` 即可离线使用
- **智能排序** — 按拼音排序描述，同系列按序号升序

## 快速开始

### 1. 准备图片

按 `描述-序号.格式` 命名，放入同一文件夹：

```
📁 明信片作品/
├── 秋日湖畔-1.png
├── 自然之美-2.png
├── 草原牧歌-3.webp
└── 雪山晨曦-4.jpg
```

- 建议尺寸：1480 × 880px 或以上，横版
- 支持格式：PNG / JPG / JPEG / WEBP / BMP / GIF

### 2. 打开网站

访问 [在线版](https://frog1205.github.io/postcard-gallery/)，或将 `index.html` 拖入浏览器打开。

### 3. 加载 & 浏览

点击 **「选择图片文件夹」** → 选择文件夹 → 作品自动展示。

### 4. 打印明信片

点击 **「明信片打印」** → 预览正反面 → 打印。

推荐打印设置：

| 设置项 | 值 |
|-------|---|
| 纸张 | A6（148×105mm） |
| 方向 | 横向 |
| 缩放 | 100% |
| 边距 | 无 |
| 背景图形 | 勾选 |

推荐用纸：300g 铜版纸 / 哑光卡纸。

## 技术栈

- 原生 HTML / CSS / JavaScript，零依赖
- File System Access API（需 Chrome 86+ / Edge 86+）
- CSS Grid + Flexbox 响应式布局
- Print media queries 精确控制打印样式
