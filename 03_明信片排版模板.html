石渠 AI 文创课 · A6 明信片排版模板

本文件包含 4 个打印页面：A4 拼版正面、A4 拼版背面（镜像对位）、单张 A6 正面、单张 A6 背面。

使用步骤：

  1. 用 Chrome / Edge 打开本 HTML。
  2. 把学员图保存到本文件同目录，命名如 img/zhaxi_yak.png。
  3. 在源码搜索 data-student，按上方注释替换 background-image 路径与"姓名 / 日期 / 寄语标题"。
  4. Ctrl/Cmd + P 打印：A4 横向、缩放 100%、边距 0、勾选背景图形、双面沿长边翻转。
  5. 打印后沿中线裁切，得到 2 张 A6 明信片。

批量做法：复制 .page 整块，对应正面和背面页一起增加；或把多名学员的图按顺序排进同一份拼版。

三个温柔的寄语题目（给学员选）

  1. 写给三年后的自己——你希望那时候的你过得怎么样？
  2. 写给阿妈 / 阿爸——一句你平时没说出口的话。
  3. 写给来过石渠的远方朋友——你想让 TA 知道什么？

设计说明

  • 主色：扎溪卡夕阳暖橙 #E8A02C + 嘛呢经墙朱砂 #B8332C + 米白底 #FFF8E7
  • 正面右下"五色条"= 五色经幡顺序（蓝/白/红/绿/黄）
  • 背面遵循国际明信片版式：左寄语 / 右地址 + 邮票位 / 六格邮编
  • 所有横线为印刷淡米色 #E8D9B0，不影响学员手写阅读
